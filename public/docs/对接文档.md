# 前端与三维交互（调用说明）

完整接入步骤见：[frontend-integration.md](./frontend-integration.md)。演示页：[`../demo.html`](../demo.html)。

## 父 → 三维：推送

```js
iframe.contentWindow.postMessage(
  {
    type: 'MODEL_UPDATE',
    objects: [
      {
        objectName: 'BIM_主机_1_',
        metrics: { 压缩机运行电流: 550, 冷凝压力: 35.2 },
      },
    ],
  },
  '*',
)
```

或：`{ cmd: 'MODEL_UPDATE', param: { objects: [...] } }`

- `objectName` 与模型 `BIM_*` 设备名匹配，尾部 `_` 可有可无。
- 收到 `onLoaded` 后首推，之后定时推送。

### 取消设备选中

点击模型后三维会高亮选中设备，并通过 `web3dDeviceClick` 回传。父页面关闭详情等场景可通知三维取消选中效果：

```js
iframe.contentWindow.postMessage({ type: 'CLEAR_DEVICE_SELECTION' }, '*')
// 或：{ cmd: 'CLEAR_DEVICE_SELECTION' }
```

## 三维 → 父：回传

```js
window.addEventListener('message', (event) => {
  if (event.source !== iframe.contentWindow) return
  const { cmd, param } = event.data || {}
  if (cmd === 'onLoaded') { /* 首次推送 */ }
  if (cmd === 'web3dDeviceClick') { /* param: { objectName, metrics } */ }
  if (cmd === 'web3dDevicePanelClose') { /* param: { objectName } */ }
})
```

| cmd | param |
|-----|--------|
| `onLoading` | — |
| `onLoaded` | — |
| `web3dDeviceClick` | `{ objectName, metrics }` |
| `web3dDevicePanelClose` | `{ objectName }` |
